# Contributing

This project follows the standards defined in `docs/standards/`. Before
contributing:

1. Read `docs/onboarding/DEVELOPER_ONBOARDING.md`.
2. Set up your local environment per `docs/onboarding/LOCAL_DEV_SETUP.md`.
3. Follow `docs/standards/GIT_WORKFLOW.md` for branching.
4. Follow `docs/standards/COMMIT_CONVENTIONS.md` for commit messages.
5. Open PRs against `develop` following `docs/standards/PR_POLICY.md`.
6. Ensure `scripts/lint.sh` and `scripts/test.sh` pass before requesting review.

All contributions must pass CI (see `docs/ci-cd/CI_CD_FOUNDATION.md`) and satisfy
the quality gates defined in `docs/standards/CODING_STANDARDS.md`.

No business logic, feature work, or HMEOS integration code may be merged until
Sprint 1 is formally accepted and Sprint 2 is authorized.
